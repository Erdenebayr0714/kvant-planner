# Квант Майнинг ХХК — Засварын сарын планер

БЕЛАЗ тэрэгний цахилгаан хөдөлгүүрийн засвар үйлчилгээний **сарын төлөвлөгөө**.
Нэвтрэх нэр/нууц үгээр ордог, эрхийн зэрэглэлтэй (Админ / Засварлагч / Харагч),
удирдлагууд нэг өгөгдлийг хамтдаа харж, засдаг веб апп.

Энэ гарын авлага нь **үнэгүй** хостинг дээр байрлуулах алхмуудыг зааж өгнө.
Programmer байх шаардлагагүй — доорх алхмуудыг дараалан дагана.

Ерөнхий бүтэц: **Neon** (өгөгдлийн сан, үнэгүй) + **Render** (сервер, үнэгүй) + **GitHub** (кодоо байршуулах газар, үнэгүй).

Байрлуулахад ойролцоогоор **20-30 минут** зарцуулна.

---

## Хэсэг 1 — Өгөгдлийн сан үүсгэх (Neon)

1. https://neon.com руу орж **Sign up** дар (Google хаягаар нэвтэрвэл хялбар).
2. **Create project** дарж, нэр өг (жиш: `kvant-planner`). Бүс (region) нь дурын. **Create** дар.
3. Гарч ирэх **Connection string**-ийг бүтнээр нь хуулж ав. Иймэрхүү харагдана:

   ```
   postgresql://user:password@ep-xxxx.aws.neon.tech/dbname?sslmode=require
   ```

   Хэрэв тэр даруй харагдахгүй бол зүүн талын **Connection Details** хэсгээс олно.
   👉 Энэ мөрийг түр хадгалж ав — Хэсэг 3-д хэрэгтэй.

> Neon-ийн үнэгүй багц энэ хэмжээний ажилд хангалттай. Өгөгдөл байнга хадгалагдана.

---

## Хэсэг 2 — Кодыг GitHub-д байршуулах

1. https://github.com руу орж бүртгүүл / нэвтэр.
2. Баруун дээд булангийн **+** → **New repository** дар.
3. Нэр өг (жиш: `kvant-planner`), доор **Private**-ийг сонговол зөвхөн та харна. **Create repository** дар.
4. Дараагийн хуудсанд **"uploading an existing file"** гэсэн холбоос дээр дар.
5. Танд өгсөн багцын **бүх файл, `public` фолдерын хамт** чирж оруул:
   - `package.json`, `server.js`, `db.js`, `.env.example`, `.gitignore`, `render.yaml`, `README.md`
   - `public/` фолдер (доторх `login.html`, `app.html`, `logo.png`-ийн хамт)
   - ⚠️ `node_modules` фолдер, `.env` файлыг **БҮҮ оруул** (шаардлагагүй, нууц мэдээлэл агуулна).
6. Доор **Commit changes** дар.

> Тайлбар: GitHub дээр фолдер оруулахдаа `public` доторх файлуудыг оруулахад
> зам нь `public/login.html` гэж хадгалагдсан байх ёстой. Чирж оруулахад автоматаар зөв болно.

---

## Хэсэг 3 — Серверт байрлуулах (Render)

1. https://render.com руу орж **Sign up** дар. **GitHub-аар нэвтэр** (ингэвэл кодоо шууд холбоно).
2. Дашбоард дээрээ **New +** → **Web Service** дар.
3. Дөнгөж үүсгэсэн `kvant-planner` репозиторио сонго (шаардвал GitHub-д зөвшөөрөл өг).
4. Тохиргоог дараах байдлаар бөглө:
   - **Name:** `kvant-planner` (дурын)
   - **Region:** дурын (жиш: Singapore)
   - **Branch:** `main`
   - **Runtime / Language:** Node
   - **Build Command:** `npm install`
   - **Start Command:** `node server.js`
   - **Instance Type:** **Free**
5. Доош гүйлгээд **Environment Variables** хэсэгт дараах 5 хувьсагчийг нэмнэ
   (**Add Environment Variable** дарж нэг бүрчлэн):

   | Key (нэр)        | Value (утга)                                        |
   |------------------|-----------------------------------------------------|
   | `DATABASE_URL`   | Хэсэг 1-д хуулж авсан Neon-ийн холболтын мөр         |
   | `SESSION_SECRET` | Урт санамсаргүй тэмдэгт (доор тайлбар)               |
   | `ADMIN_USER`     | `admin`                                             |
   | `ADMIN_PASSWORD` | Өөрийн хүчтэй нууц үг (жиш: `Kvant#2026!`)           |
   | `NODE_ENV`       | `production`                                         |

   **`SESSION_SECRET` гэж юу вэ?** — нэвтрэлтийг хамгаалдаг нууц түлхүүр.
   Ямар ч урт, санамсаргүй үсэг тоо байж болно (жиш: `f9a2c7...` 40+ тэмдэгт).
   Нэг тавьсан бол дараа нь бүү өөрчил (өөрчилвөл бүх хүн дахин нэвтрэх шаардлагатай болно).

6. **Create Web Service** дар. Render 2-3 минут байрлуулна. Лог дээр
   `✓ Сервер ажиллаж байна` болон `✓ Админ хэрэглэгч үүслээ` гэж гарвал бэлэн.

7. Дээд талд гарах хаяг (жиш: `https://kvant-planner.onrender.com`)-аар нэвтэр:
   - **Нэвтрэх нэр:** `admin` (эсвэл `ADMIN_USER`-т тавьсан утга)
   - **Нууц үг:** `ADMIN_PASSWORD`-т тавьсан утга
   - Нэвтэрсэн даруй баруун дээд булангийн 🔑 товчоор **нууц үгээ солиорой**.

> **Санамж:** Render-ийн үнэгүй сервер 15 минут ашиглаагүй бол "унтаж",
> дараа нь анх нээхэд эхний ачаалалт ~1 минут удаж магадгүй. Дараа нь хэвийн хурдтай.
> Тасралтгүй хурдан байлгах шаардлагатай бол Render-ийн төлбөртэй багц руу шилжиж болно.

---

## Хэсэг 4 — Хэрэглэгч нэмэх ба ашиглах

Админаар нэвтэрсний дараа баруун дээд булангийн **👥** товчоор хэрэглэгч удирдана:

- **Нэр**, **Нэвтрэх нэр** (латин үсэг/тоо), **Нууц үг**, **Эрх** сонгож нэмнэ.
- Дараа нь тухайн хүнд нэвтрэх нэр, нууц үг болон сайтын хаягийг өг.

**Эрхийн зэрэглэл:**

- **Админ** — бүх зүйл: ажил нэмэх/засах/устгах, хэрэглэгч удирдах.
- **Засварлагч** — ажил нэмэх, засах, устгах (хэрэглэгч удирдахгүй).
- **Харагч** — зөвхөн харах (удирдлага, хяналтад тохиромжтой).

**Планерын боломжууд:**

- Сар сонгох (‹ ›), нийт/хийгдэж буй/дууссан/хойшилсон тоо, гүйцэтгэлийн хувь.
- Машин, хөдөлгүүр, ажлын төрөл, хариуцах баг, сэлбэг, хугацаа, статус.
- Баруун талд сарын **Gantt** харагдац (ажил бүр огнооныхоо дагуу өнгөт зураасаар).
- Хайлт, статусаар/багаар шүүх, **Хэвлэх / PDF**.

## Нэмэлт: Локал компьютер дээр туршиж үзэх (заавал биш)

Хэрэв танай IT ажилтан эхлээд өөрийн компьютер дээр туршихыг хүсвэл:

```bash
npm install
cp .env.example .env      # дараа нь .env дотор DATABASE_URL болон SESSION_SECRET-ээ бөглөнө
npm start
```

Дараа нь хөтчөөр `http://localhost:3000` руу орж нэвтэрнэ.
(Node.js 18+ болон PostgreSQL холболт шаардлагатай.)

---

## Аюулгүй байдлын зөвлөмж

- Нууц үгсийг хүчтэй (8+ тэмдэгт, том/жижиг үсэг, тоо, тэмдэгт) байлга.
- `.env` файл болон нууц үгсийг хэн нэгэнд бүү дамжуул, GitHub-д бүү оруул.
- Ажлаас гарсан хүний хэрэглэгчийг 👥 хэсгээс шууд устга.
- Нууц үгсийг файлд задгайгаар хадгалдаггүй — өгөгдлийн санд шифрлэгдэж (bcrypt) хадгалагдана.

хүсвэл над руу хэлээрэй.
